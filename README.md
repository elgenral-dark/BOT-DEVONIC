# Installation

<div align="center">

### Termux (Android)

```bash
termux-setup-storage
pkg update -y && pkg upgrade -y
pkg install git nodejs -y
git clone [https://github.com/moa926032-hub/BOT-DEVONIC.git](https://github.com/moa926032-hub/BOT-DEVONIC.git)
cd BOT-DEVONIC 
npm install
npm start
```
